# ✨ BioFile

**Your very own corner of the internet.**

BioFile is a web app that lets you create a beautiful, fully custom profile page — your personal corner of the internet — inspired by identity linkers like **bio.link** and **guns.lol**.

Share your story, your vibe, your links — all in one place, styled by you.

---

## 🌟 Features

- 🪪 **Create your own profile** — identity pages made simple
- 🎨 **Fully custom design** — powered by **Tailwind CSS** for limitless styling
- 🔗 **Share anywhere** — one link, your whole story
- ⚡ **Fast & lightweight** — built for quick loading

## 🛠 Tech Stack

- ⚛️ **React** + **Vite**
- 🎨 **Tailwind CSS** for custom UI

## 🚀 Getting Started

```bash
# clone
git clone <your-repo-url>

# install
cd biofile
npm install

# run
npm run dev
```
